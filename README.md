# Билеты на концерт

Java, блок 2, части 1–2. Вариант 11.

`ConcertTicket` — абстрактный билет. `UserSubscription` рассчитывает билет физического лица, `CorporateSubscription` — групповой заказ на несколько мест. Названия наследников сохранены из задания. Индивидуальный пропуск корпоративному заказу не применяется.

`TicketOffice` получает `NotificationService` через конструктор. `SmsNotification` и `EmailNotification` выводят уведомления в консоль; реальные сообщения не отправляются.

## Запуск

Нужен JDK 17 или новее. Из папки проекта:

```sh
javac -encoding UTF-8 -d out -sourcepath src src/Main.java
java -cp out Main
```

В IntelliJ IDEA запустить `Main`. Программа демонстрирует три индивидуальных билета, корпоративный заказ на 5 мест и обработку неверных данных. Итог: 4 оплаченных заказа, 48300 рублей.

## Структура

- `src/model` — билеты и дополнительный пропуск.
- `src/billing` — учёт оплат.
- `src/service` — интерфейс уведомлений.
- `src/service/impl` — SMS и Email.
- `src/Main.java` — запуск и демонстрация.
- `отчет.docx` — отчёт с UML и скриншотами консоли.
